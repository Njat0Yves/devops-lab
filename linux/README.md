# Linux System Monitor

A lightweight Bash script for displaying basic Linux system information and resource usage.

## Features

The script displays:

- Hostname
- Operating system
- Kernel version
- System uptime
- CPU usage
- Memory usage
- Disk usage
- Logged-in users
- Top CPU-consuming processes

## Usage

Make the script executable:

```bash
chmod +x system-monitor.sh

Run the monitor:

./system-monitor.sh
